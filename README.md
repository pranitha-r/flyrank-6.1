## 3. How to Enable GitHub Pages (To make it live)
1. Go to your repository on GitHub: [https://github.com/pranitha-r/flyrank-6.1](https://github.com/pranitha-r/flyrank-6.1)
2. Click **Settings** (top right tab).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select `main`
   - Select `/ (root)` folder
   - Click **Save**.
5. In 1–2 minutes, your portfolio will be published live at:
   `https://pranitha-r.github.io/flyrank-6.1/`
